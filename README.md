# SEO Baza Writer

Скілл для Claude, який пише український SEO-контент у стилі [SEO Baza](https://seobaza.com.ua): новини, аналітичні статті, п'ятничні дайджести, серіали з 🍿, практичні гайди, а також пости для Telegram, Facebook, LinkedIn, Instagram і Threads.

Всередині: голос і формати SEO Baza, дистильовані з місяців реальних редакторських правок. BLUF-відкриття, нуль води, нуль ем-тире, прості слова замість жаргону, окремі правила форматування для сайту і для кожної соцмережі, еталонні приклади опублікованих постів.

## Встановлення

### Варіант 1: як плагін (рекомендовано)

У Claude Code:

```
/plugin marketplace add fajela/seobaza-writer
/plugin install seobaza-writer@seobaza
```

### Варіант 2: скопіювати скілл вручну

Скопіюй папку `skills/seobaza-writer/` у свою папку скілів:

- для всіх проєктів: `~/.claude/skills/seobaza-writer/`
- для одного проєкту: `.claude/skills/seobaza-writer/` у корені проєкту

### Варіант 3: claude.ai

Заархівуй папку `skills/seobaza-writer/` у zip і завантаж у Settings → Capabilities → Skills.

## Використання

Просто попроси Claude написати матеріал:

```
напиши новину: Google запустив ...  джерело: https://...
напиши п'ятничні новини з цих джерел: ...
напиши статтю про це дослідження + ТГ-пост
```

Скілл сам спитає, чого бракує (тип матеріалу, джерела, кут подачі), і видасть готовий `.mdx` із frontmatter. URL він ніколи не вигадує: якщо джерела не дати, поставить плейсхолдер `[посилання]`.

## Що всередині

```
skills/seobaza-writer/
├── SKILL.md                      # головна інструкція: формати, структури, чекліст
└── references/
    ├── style-rules.md            # повні правила стилю (пунктуація, мова, посилання, соцмережі)
    └── style-examples.md         # еталонні приклади з опублікованих матеріалів
```
